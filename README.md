# IWLA Playground

Disposable test copy of the Arlington-Fairfax Chapter (IWLA) site, built on [WordPress Playground](https://playground.wordpress.net). Runs entirely in the browser; nothing is saved between sessions.

Open: https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/shankardba/iwla-playground/main/blueprint.json

Contents: `blueprint.json` (setup steps), `iwla-modern.zip` (theme + seed content script), `media/` (placeholder banner photos), `build.sh` (regenerates the zip and blueprint from the theme source).
